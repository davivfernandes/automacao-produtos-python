# Automação de Cadastro de Produtos em Python

Projeto desenvolvido durante meus estudos de Python na Jornada Python da Hashtag Treinamentos.

A aplicação automatiza o processo de cadastro de produtos em um sistema web utilizando dados de uma base em CSV.

## Tecnologias utilizadas

- Python
- PyAutoGUI
- Pandas
- Automação de tarefas

## Como funciona

O programa:

1. Abre o navegador automaticamente
2. Acessa o sistema de cadastro
3. Lê uma base de produtos em CSV
4. Percorre os produtos da tabela
5. Preenche automaticamente os campos do sistema
6. Cadastra os produtos sem necessidade de digitação manual

## Dados utilizados

A base contém informações como:

- Código
- Marca
- Tipo
- Categoria
- Preço
- Custo
- Observações

## Objetivo do projeto

Praticar automação de tarefas repetitivas utilizando Python e compreender como dados estruturados podem ser utilizados para automatizar processos.

## Aprendizados

Durante o desenvolvimento pratiquei:

- Manipulação de dados com Pandas
- Leitura de arquivos CSV
- Estruturas de repetição
- Automação de teclado e mouse com PyAutoGUI
- Integração entre dados e aplicações web
